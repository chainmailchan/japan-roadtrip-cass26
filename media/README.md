# media/

Put your own photos (and short video clips) here, then refer to them in the
`photo` or `media` column of your Places sheet as `media/your-file.jpg`.

- Upload on GitHub: open this folder → **Add file → Upload files** → drag files in → **Commit changes**.
- Use **JPG/PNG/WebP**, ideally about 1600 px wide (phone photos are often 4–8 MB; smaller files load much faster).
  iPhone **HEIC** photos won't show in most browsers — export as JPG first.
- Use simple file names without spaces, e.g. `kamakura-komachi-dori.jpg`.
- Videos: short **.mp4** clips (under ~20 MB) can live here. For anything longer, upload to YouTube as
  *Unlisted* and paste the YouTube link instead.
